# โหมดจัดหน้าจอ — ข้อเสนอ

> สถานะ: กลุ่ม A + Undo + Named Layouts บิ้วแล้วใน v1 (27 ก.ย. 2026) — Focus ใช้ความกว้าง 80% เต็มความสูง · สถานะล่าสุดดูตารางใน CLAUDE.md

ทุกโหมดทำงานแบบเดียวกัน: เก็บรายชื่อหน้าต่างที่มองเห็นอยู่บนจอ → คำนวณตำแหน่งใหม่ → ย้าย/ย่อ/ขยายผ่าน Accessibility API
ทุกโหมดเคารพ **ขอบจอที่ใช้ได้จริง** (ไม่ทับ Menu Bar และ Dock) และมี **ช่องไฟ (gap)** ปรับได้

## กลุ่ม A — จัดเรียงทันที (กดครั้งเดียวจบ)

| # | โหมด | ภาพในหัว | เหมาะกับ | Hotkey เสนอ |
|---|------|----------|----------|-------------|
| 1 | **Grid** | แบ่งจอเป็นตาราง 2×2, 3×2 … ตามจำนวนหน้าต่าง | เปิดไว้หลายแอป อยากเห็นครบทุกตัว | ⌃⌥G |
| 2 | **Focus** | แอปหน้าสุดขึ้นกลางจอ ~80% แอปอื่นซ่อน (Hide) | ทำงานจดจ่อ อ่านเอกสาร | ⌃⌥F |
| 3 | **Split** | 2 แอปล่าสุด ซ้าย-ขวา 50/50 (สลับเป็น 60/40 ได้) | เทียบเอกสาร / ก๊อปข้อมูลข้ามแอป | ⌃⌥S |
| 4 | **Main + Stack** | แอปหลักกินซ้าย 60% ที่เหลือซ้อนแนวตั้งด้านขวา | เขียนโค้ด (Editor หลัก + Terminal/Browser ข้าง) | ⌃⌥M |
| 5 | **Cascade** | เรียงเฉียงซ้อนกันเหมือนไพ่ เห็นแถบหัวทุกหน้าต่าง | สลับไปมาหลายหน้าต่างของแอปเดียว | ⌃⌥C |
| 6 | **Clean Desk** | ซ่อนทุกแอป เหลือแค่ Desktop โล่ง ๆ (กดซ้ำ = คืนค่า) | แชร์จอ / ถ่ายภาพหน้าจอ / พักสายตา | ⌃⌥D |

## กลุ่ม B — Layout ที่บันทึกไว้ (Workspace Presets)

| # | โหมด | ทำอะไร |
|---|------|--------|
| 7 | **Snapshot & Restore** | กด "จำ" ตำแหน่งทุกหน้าต่างตอนนี้ แล้วกด "คืน" ภายหลัง — กันจอรกหลังเสียบ/ถอดจอนอก |
| 8 | **Named Layouts** | ตั้งชื่อชุดจัดวาง เช่น "Coding" (VS Code ซ้าย, Terminal ขวาล่าง, Chrome ขวาบน) / "Meeting" (Zoom + Notes) — กดแล้วเปิดแอปที่ขาดให้ด้วย |

## กลุ่ม C — ส่วนเสริม (ทำทีหลัง)

| # | ฟีเจอร์ | ทำอะไร |
|---|---------|--------|
| 9 | **Multi-display** | เลือกได้ว่าจะจัดเฉพาะจอที่เมาส์อยู่ หรือทุกจอ · ส่งหน้าต่างข้ามจอ |
| 10 | **Exclude list** | รายชื่อแอปที่ห้ามแตะ (เช่น Finder, System Settings, หน้าต่างลอยของ Zoom) |
| 11 | **Snap by hotkey** | ⌃⌥←/→/↑/↓ ส่งหน้าต่างปัจจุบันไปครึ่งจอ / มุมจอ |
| 12 | **Undo** | ย้อนการจัดครั้งล่าสุด (เก็บ snapshot อัตโนมัติก่อนจัดทุกครั้ง) |

## ลำดับที่แนะนำให้บิ้ว

1. **Grid** — พิสูจน์ว่าอ่าน/ย้ายหน้าต่างได้จริง (ท่อหลักทั้งหมดผ่านที่นี่)
2. **Undo + Snapshot/Restore** — ได้ของฟรีจากท่อเดียวกัน และทำให้ลองโหมดอื่นได้ไม่กลัวพัง
3. **Focus, Split, Main + Stack** — แค่เปลี่ยนสูตรคำนวณ
4. **Clean Desk, Cascade**
5. **Named Layouts, Multi-display, Exclude list, Snap**
